## What is Scowport ?

Scowport is a web app for [Zusam](https://github.com/zusam/zusam). It started as a hard fork of Zusam's web app, and over time will build into it's own thing.


## Features

- Links preview and embedded youtube, vimeo, imgur, soundcloud, twitch, bandcamp...
- Video and image upload
- Photo albums
- Completely responsive and mobile friendly
- Full Zusam feature support
