# Contributing to Scowport

Thank you for considering contributing to Scowport! There are many ways that you can help, some of which are outlined below.

## Report bugs and issues or request features

If you find a problem with Scowport, or if you think of a valuable feature you would like implemented, open a new issue on GitHub and describe it for us.

If you find a security vulnerability, do NOT open an issue. Please instead use the [GitHub security disclosure](https://github.com/Neriderc/scowport/security) functionality. Also see [SECURITY.md](./SECURITY.md).
